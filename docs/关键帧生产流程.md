# 短剧关键帧生产流程（Qwen-Image 2.1 · 已验证）

> 本文是《乾隆》《凤鸣》两本剧实际跑通后的固化流程，换机器照抄即可。

> 详细对比新旧版本架构差异与跨题材通用化说明，见 [关键帧管线升级对比说明](./关键帧管线升级对比说明.md)。

## 总览

```
① 素材        outline.json / cast.json / art.json / storyboard.json
                    │
② 定妆照      build_cast.py  →  8 个角色，2:3 全身，浅灰影棚
                    │
③ 参考图入库   setup_cast.py  →  服务器 /ComfyUI/input/cast/<tag>/C01.png
                    │
④ 关键帧      build_shots.py --ref  →  run_shots.py（图生图，带参考图）
                    │
⑤ 回传        pull_frames.py / 自动下载  →  projects/<剧>/storyboard/frames/
                    │
⑥ 推送        publish.ps1  →  GitHub
```

## 素材要求

每本剧在 `projects/<project>/` 下必须有：

| 文件 | 内容 | 用途 |
|---|---|---|
| `characters/cast.json` | 角色外观、年龄、发型服饰、`image.prompt` | 生成定妆照 & 锁定关键帧服装配饰 |
| `art/art.json` | 场景具象 `anchors`/光影、道具 `anchors` | 注入场景与道具物理锚点 |
| `script/script.json` & `staging/staging.json` | 逐拍动作与台词神态、家具站位朝向 | 驱动具体表演动作与构图调度 |
| `storyboard/storyboard.json` | `episodes[].segments[].cuts[]`（景别/运镜/6项量化构图/`frame`） | 逐镜头出图 |

## ② 定妆照

```powershell
cd scripts\render
python build_cast.py ..\..\projects\novel_01_qianlong -o tasks\cast_qianlong.json
# 可选：同时生成面部特写锚点（C0X_face，供特写镜头锁脸）与场景空镜锚点
python build_cast.py ..\..\projects\novel_01_qianlong -o tasks\cast_qianlong.json --with-face --with-scenes
# 上传并跑
python run_shots.py ...   # 或在服务器上：python3 run_shots.py cast_qianlong.json --tag cast_qianlong
```

**提示词规则**（`build_cast.py` 融合 `character-refs` 几何正面规范）：

- 全身母版（**832×1216** 2:3）：严格正对镜头（双肩/髋/脚正面、鼻梁居中、双耳可见、双臂自然下垂无道具）、纯浅灰无缝影棚背景、自然哑光肤质、无文字水印与分格边框
- 面部特写锚点（**896×1120** 4:5，`--with-face`）：85mm 胸部以上正面特写，去除下装全身词，专为特写镜头锁脸提供高质量头部基准

## ③ 参考图入库

`make_episode.py` 已内置自动同步：会优先通过 ComfyUI HTTP `/upload/image` 自动将本地 `projects/<剧>/characters/portraits/*.png` 上传至远端 `input/cast/<tag>/`，并同时保留 SSH `setup_cast.py` 兜底：

```bash
python3 setup_cast.py qianlong /ComfyUI/output/drama/cast_qianlong
# → /ComfyUI/input/cast/qianlong/C01.png ... C04.png（支持 C01_face.png）
```

## ④ 关键帧（核心 · 双 Skill 融合编译）

```powershell
# 单集一条龙：建任务 → 自动同步定妆图 → 推送执行脚本 → 生成 → 下载并拼联系表预览图
python make_episode.py ..\..\projects\novel_01_qianlong --ep 1 --tag qianlong
```

**提示词策略**（`build_shots.py --ref` 融合 `novel-*` 与 `character-refs`）：

1. **三分类提示词解耦**：自动识别「人物关键帧 / 纯道具特写 / 无人环境空镜」，空镜与道具镜不传人物参考图（`refs=[]`），绝不强塞人脸。
2. **Framing-First 置顶与去全身词防退化**：首句直接写死景别取景几何（特写强制 `"【特写镜头，胸部以上近距离肖像取景，85mm...严禁退回全身】"`）；且对特写镜头剔除`"体型"`及下装裙裤词、只锁五官年龄发型与领口配饰（若存在 `C0X_face.png` 优先使用），彻底避免 `close` 退回中远景。
3. **身份·服饰·年龄强绑定（防串脸/改龄/错时代）**：显式锁定角色年龄、发型及具体服装饰品（如金丝眼镜、米白职业西装套裙、48岁紫旗袍配翡翠胸针），多人同框按 `参考图1对应...；参考图2对应...` 逐一锚定防混脸。
4. **五合一剧本调度注入**：融合 `script.json` 节拍动作神态、`staging.json` 家具站位与 `art.json` 具象物理 `anchors`（跳过抽象 `summary` 防朝代误导），并对纸张道具声明不生成可读汉字消除乱码。
5. **结构化反向提示词 + 独立动态种子**：`run_shots.py` 将 `negative_prompt` 注入 `TextEncodeQwenImage21`，并使用基于 `sha256` 派生的非连续 `seed`。

## 质检（别省）

跑完一集先看拼图，按三类镜头交叉抽检：

1. **人物镜头**：脸是否同一张、服装是否同一套
2. **道具镜头**：婚戒/协议这类道具是否出现、是否变形
3. **场景镜头**：空镜/全景有没有被强行塞进人脸

三类都过再全量跑。（GEMINI.md 第 2 条记录过"只抽检人像导致 119 个镜头全废"的事故。）

## 换电脑跑：清单

1. 装 Python 3.9+ 与 paramiko：`pip install paramiko`
2. 复制 `scripts/remote/.env.example` 为 `.env.local`，填：
   ```
   SJ_HOST=xn-b.suanjiayun.com
   SJ_PORT=2020
   SJ_USER=18379685528
   SJ_PWD=你的密码
   SJ_INDEX=0
   ```
3. 设图片回传地址（默认已写死华南实例）：
   ```powershell
   $env:DRAMA_BASE="http://xn-b.suanjiayun.com:61146"
   ```
4. 把 `projects/<剧>/characters/portraits/` 的定妆照同步到服务器：
   `python3 setup_cast.py <tag> /ComfyUI/output/drama/cast_<tag>`（或直接重跑 build_cast）
5. 验证连通：`python selftest.py` → 应返回主机名与 GPU

> `.env.local` 已在 `.gitignore` 里，不会推到仓库；换机器必须手动重建。

## 已知限制

- **角色分辨度**：同剧两个同龄同性角色（如《凤鸣》C01/C03）容易画得像同一个人 —— 定妆阶段就要用发型/发色/服装颜色拉开差距
- **场景单一**：`art.json` 里一场戏只有一个场景时，整集会像在同一间屋子拍 —— 需要在 art.json 拆场景
- **PE 节点**：官方模板带的提示词增强节点需要额外 9G 模型，未装，选中按 `Ctrl+B` 跳过
