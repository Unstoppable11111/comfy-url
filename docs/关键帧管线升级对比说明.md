# 关键帧生产管线升级对比说明（Qwen-Image 2.1 + 双 Skill 通用融合版）

> 本文档说明本次升级版本与上一版本（基于提交 `6c42178` / `478e7cf`）的核心区别。本次升级在保持 `Qwen-Image 2.1`（`TextEncodeQwenImage21`）稳定出图的基础上，将 `.agents/skills/novel-*`（`shuohao-skills`）与 `.agents/skills/character-refs` 深度融合，打造为**跨题材、跨画幅、可复用任意新剧的通用关键帧生产管线**。

## 二、核心代码架构变化详情

### 1. 新增通用辅助模块：`scripts/render/prompt_utils.py`

将原本散落或缺失的通用逻辑抽象为无剧目依赖的纯标准库模块，由 `build_cast.py` 与 `build_shots.py` 共用：

- **`infer_era_profile(art, outline)`**：根据 `art.dynasty` 与 `outline.params.genre` 自动归类为 `modern`（现代/都市）、`ancient`（古装/朝代/仙侠/武侠）、`period`（民国/年代）、`scifi`（科幻）或 `neutral`（通用），动态输出画风后缀、空镜前缀与时代反向约束（例如古装剧自动禁止“现代西装/手机”，而不是像固定脚本那样禁止“古装长袍”）。
- **`resolve_canvas(aspect_ratio, override_size)`**：根据 `storyboard.aspectRatio` 自动映射至 Qwen-Image 2.1 的 1MP 黄金分辨率桶（`9:16` → `768×1344`、`16:9` → `1344×768`、`3:4` → `896×1152` 等），也支持命令行 `--size WxH` 手工指定。
- **`sanitize_close_appearance(text)`**：通用正则清洗器，对任何剧目角色（现代套裙/阔腿裤/皮鞋，或古装襦裙/长袍/绣花鞋）在特写镜头下自动剔除身高、体型、鞋履、下装词并转为肩领细节，无需针对某部剧写死衣服名称。
- **`strip_empty_room_clauses(text)`**：自动清除 `art.json` 光照英文提示词中自带的 `"empty interior"`、`"without people"`、`"no people"` 等无人空镜短语，防止人物镜头与光照描述自相矛盾。
- **`make_seed(namespace, *parts)`**：基于 `sha256` 为每剧、每集、每个镜头生成确定性且互相隔离的独立整数种子。

### 2. 定妆照与场景锚点构建：`scripts/render/build_cast.py`

- **几何正面规范**：融合 `character-refs` 对参考底模的要求（双肩/髋/脚正对、鼻梁居中、双耳可见、双臂自然下垂无道具、头顶与脚底留白、纯浅灰无缝影棚背景、自然哑光健康肤质）。
- **多档产出选项**：
  - 默认：Tier-1 全身正面母版（`832×1216`，`C01.png`）
  - `--with-face`：Tier-2 胸部以上特写锚点（`896×1120`，`C01_face.png`，自动调用 `sanitize_close_appearance`）
  - `--with-scenes`：纯建筑无人空镜锚点（`scene_S0X.png`，分辨率自动匹配 `--aspect` 或 `storyboard.aspectRatio`）
- **通用负向提示词**：合并基础防油光/防畸形/防拼图词、时代反向词与角色自有 `negativePrompt`。

### 3. 关键帧 Prompt 编译器：`scripts/render/build_shots.py`

1. **三分类提示词解耦**：
   - `scene`（`characters=[]` 且 `props=[]`）：`refs=[]`，输出纯建筑空镜，强制禁人；
   - `prop`（`characters=[]` 且 `props!=[]`）：`refs=[]`，输出道具微距特写，禁完整人脸与可读大字；
   - `character`（`characters!=[]`）：按需绑定 `cast_chars` 定妆照（特写优先选用 `C0X_face.png`）。
2. **Framing-First 与按景别自适应**：
   - 首句直接声明画幅取景与光学焦段（特写强制 `【特写镜头，胸部以上近距离肖像取景...严禁退回全身或半身远景，85mm人像长焦】`）；
   - 特写镜头自动对 `cut.frame`、角色外貌、剧本动作执行 `sanitize_close_appearance` 并跳过“站位于沙发/茶几旁”等会拉远景别的空间词。
3. **动态 Negative Prompt 合成**：综合基础防塑料/防油光/防乱码词、时代反向词、角色 `negativePrompt`（以及空镜/道具镜的人脸禁止词）并去重保序。

### 4. 执行器与全自动流水线：`run_shots.py` / `setup_cast.py` / `make_episode.py`

- **`run_shots.py`**：
  - 将任务 JSON 的 `negative_prompt` 真实写入 `TextEncodeQwenImage21`；
  - 优先采用任务自带的确定性 `seed`；
  - 开放 `--cfg`、`--steps`、`--resolution`、`--sampler`、`--scheduler`、`--unet`、`--clip`、`--vae` 全参数；
  - 支持直接传相对路径或 `cast/<cast-tag>/<id>.png`，提交失败自动重试 1 次并打印 `status.messages` 详情。
- **`setup_cast.py`**：使用正则 `_\d+_$` 剥离 ComfyUI 输出编号后缀，保留 `C01_face` 等后缀命名，修复旧版 `split("_")[0]` 会覆盖 `C01.png` 的隐患。
- **`make_episode.py`**：
  - 支持 `--ep 0` 一键生成全剧所有集、`--cast-tag`、`--base`、`--cfg`、`--size`；
  - 开跑前自动通过 ComfyUI `/upload/image` HTTP 接口将本地 `characters/portraits/*.png` 同步至远端 `input/cast/<cast_tag>/`（换新实例无需手动拷图），并同步推送最新 `run_shots.py`；
  - 回传后自动合成 `docs/previews/sheet_<tag>_ep<N>.jpg` 联系表预览图。

## 四、通用新剧接入与使用方式

对任意遵循（或部分遵循）目录结构的新短剧项目目录 `<new_drama_dir>`（仅需具备 `art/art.json`、`characters/cast.json`、`storyboard/storyboard.json`，其余 `outline/script/staging` 有则自动增强、缺省也不报错）：

```powershell
cd scripts\render

# 1. 生成定妆照（与可选面部特写锚点、纯场景空镜锚点）任务清单
python build_cast.py <new_drama_dir> -o tasks\cast_new.json --with-face --with-scenes

# 2. 生成指定集或全集关键帧任务清单（自动匹配朝代与 aspectRatio）
python build_shots.py <new_drama_dir> -o tasks\shots_new_ep1.json --ep 1 --ref

# 3. 有云端 4090 实例时，单命令跑完单集/全集（--ep 0）
python make_episode.py <new_drama_dir> --ep 1 --tag <new_tag>
```
