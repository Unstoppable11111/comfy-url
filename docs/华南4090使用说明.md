| 用途 | 路径 | 大小 |

## 工作流

`/ComfyUI/user/default/workflows/`：

- `image_qwen_image_2_1_t2i.json` 文生图
- `image_qwen_image_2_1_image_edit.json` 图像编辑
- `image_qwen_image_2_1_turbo_t2i.json` Turbo 文生图
- `image_qwen_image_2_1_turbo_image_edit.json` Turbo 图像编辑

## 参数

euler / simple，25 步，cfg 1.0，1024×1024。
**实测 4090：一张约 32 秒**（3090 上是 165 秒）。

## 启停

```bash
/sj-run.sh -r     # 重启（8080）
/sj-run.sh -t     # 停止
```

手动：

```bash
cd /ComfyUI && nohup /root/miniconda3/bin/conda run -n comfyui \
  python main.py --listen 0.0.0.0 --port 8080 --enable-cors-header --enable-manager \
  > /ComfyUI/comfyui.log 2>&1 &
```

## 注意

1. **提示词增强 PE 节点**缺 9G 的 `qwen3.5_9b_..._pe_t2i` 编码器，节点会标红；
   选中按 `Ctrl+B` 跳过，不影响出图。
2. 系统盘 30G，当前用 17G（模型 16.2G），剩 14G。别再往系统盘塞大模型。
3. 数据盘 `/root/sj-tmp` 50G，网盘 `/root/sj-fs`（**华南 A 区网盘在释放实例后会丢**）。
4. 公共模型库 `/root/sj-data` 挂载了 8T，但 `Qwen-Image-2.1` 目录是空的。
5. 回滚点：升级前的 commit 记在 `/root/backup_head.txt`（`git checkout` 可回旧版）。
6. 下载模型用 aria2 8 线程可到 **36MB/s**（单线程只有 12.5MB/s，平台按连接限速）。
