# Qwen 模型落地全流程（2026-11 版）

> 面向 AI 短剧生产：剧本 → 分镜 → 关键帧 → 图生视频。
> 环境：算家云 GPU 实例（华北/华南分区独立）。

---

## 一、先分清：Qwen 有三条产品线，别混

| 产品线 | 最新开源版 | 干什么 | 输出 | 显存（24G 单卡） |
|---|---|---|---|---|
| **Qwen3.5** | 0.8B / 2B / 4B / 9B / 27B / 35B-A3B / 122B-A10B / 397B-A17B | 文本 + 图片理解 + 视频理解，写剧本、拆分镜、写提示词、审图 | 文字 | 9B ✅（bf16 约 18G，上下文别开太大）4B ✅ 27B ❌ 35B-A3B 需 int4 量化 |
| **Qwen-Image 2.1** | int8 / bf16 / turbo | 文生图、图像编辑、多图参考 | 图片 | ✅ 原生支持 |
| **Qwen3-TTS** | 0.6B / 1.7B / VoiceDesign | 配音、音色克隆 | 音频 | ✅ |

**关键区别**：Qwen3.5 是"能看懂图的文字模型"，Qwen-Image 2.1 是"能画图的模型"。做短剧两个都要，但用途完全不同。

---

## 二、按场景选型（短剧生产）

| 你要做的事 | 用哪个 | 怎么跑 |
|---|---|---|
| 写剧本、分集梗概、台词 | Qwen3.5-9B | vLLM 或平台镜像 |
| 把剧本拆成分镜表（景别/机位/时长） | Qwen3.5-9B | 同上 |
| 写画面提示词（中文，带细节） | Qwen3.5-9B | 同上 |
| 审图：出的关键帧对不对 | Qwen3.5-9B（能看图） | 同上 |
| 出角色定妆、场景空镜、关键帧 | Qwen-Image 2.1 | ComfyUI |
| 角色一致性（换姿态/表情/机位） | Qwen-Image 2.1 + image_edit | ComfyUI 工作流 |
| 配音、音色克隆 | Qwen3-TTS | 已有工作流 |
| 关键帧 → 视频 | 不是 Qwen（Wan2.2 / SkyReels） | 另装 |

**不建议上 27B/35B**：27B 是 dense，bf16 要 54G，24G 卡塞不下；35B-A3B 虽然只激活 3B，但权重 70G。写提示词这种事 9B 已经够用，显存翻四倍换不来四倍效果。

## 三、三条落地路径（按快慢排序）

### 路径 A：平台镜像（最快，0 部署）

算家云「镜像社区」里已有：

- `qwen3.5-9b & 3.5-27b & 3.5-35b`（标签：代码生成 / 图片理解）→ 文本线
- `MiniMax-H3`、`ComfyUI-LTX-2.3` 等 → 视频线

**适合**：只想快点用上 Qwen3.5 写东西。
**注意**：镜像里的模型版本、推理框架（vLLM/SGLang）不一定是你要的，开机后先验。

### 路径 B：自己部署（可控，30~60 分钟）

- **文本线**：vLLM 起 OpenAI 兼容服务（命令见第五节）
- **生图线**：`scripts/setup/deploy_qwen21.py` 一条命令装完 ComfyUI + Qwen-Image 2.1

**适合**：要做批量生产、要接自己的流水线。

### 路径 C：混合（推荐）

文本用平台镜像（省事），生图用脚本部署（可控），两条线跑在同一台机器上（24G 卡同时跑 9B + 生图会紧张，建议分开或错峰）。

## 四、标准流程（七步）

```
① 选机器  →  ② 选镜像  →  ③ 起服务  →  ④ 验证
                                              ↓
⑦ 收尾备份  ←  ⑥ 出关键帧/视频  ←  ⑤ 接入生产
```

### ① 选机器

| 项目 | 要求 | 说明 |
|---|---|---|
| 显卡 | 4090 / 3090 24G | 生图要 24G；9B 文本 24G 富余 |
| 系统盘 | ≥ 30G，建议 50G | 生图模型 17G |
| 数据盘 | 有就挂 | 50G，放视频模型 |
| 公网带宽 | 100M 起步 | 下 16G 要 21 分钟；装环境时临时开 1G |
| 分区 | 华北 / 华南 | **自定义镜像不能跨区**，选之前想好 |

### ② 选镜像

| 目标 | 选择 |
|---|---|
| 只跑 Qwen3.5 | 镜像社区 `qwen3.5-9b...` |
| 只跑生图 | 自己的镜像（同区）/ `deploy_qwen21.py` |
| 两个都要 | 基础镜像 Ubuntu 22.04 + 自己装 |

### ③ 起服务

**文本（vLLM）**
```bash
pip install vllm
vllm serve Qwen/Qwen3.5-9B \
  --served-model-name qwen3.5-9b \
  --port 8000 \
  --max-model-len 32768 \
  --gpu-memory-utilization 0.85
```

**生图（ComfyUI）**
```bash
/root/start_comfy.sh          # 端口 8081
```

### ④ 验证（别跳过）

```bash
# 文本服务活着吗
curl -s http://127.0.0.1:8000/v1/models | head -c 300

# 生图服务活着吗
curl -s http://127.0.0.1:8081/system_stats | head -c 300

# 生图真能出图（约 2.5 分钟）
python3 scripts/render/smoke.py
```

### ⑤ 接入生产

**文本：OpenAI 兼容接口**
```bash
curl http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3.5-9b","messages":[{"role":"user","content":"把这个场景拆成 5 个分镜"}]}'
```

**生图：ComfyUI 工作流**
- 文生图：`image_qwen_image_2_1_t2i`
- 图生图（保角色）：`image_qwen_image_2_1_image_edit`
- 参数：euler / simple，25 步，cfg 1.0，1024×1024
- PE 节点缺模型 → 选中按 `Ctrl+B` 跳过

**批量**：`/prompt` 接口循环提交，参考 `scripts/render/smoke.py` 的写法。

### ⑥ 出关键帧 → 图生视频

```
定妆图 → 每个镜头 image_edit（带角色参考）→ 关键帧
关键帧 → Wan2.2 / SkyReels（需另装模型）→ 5 秒片段
```

### ⑦ 收尾

```bash
/sj-run.sh -t          # 停服务（存镜像前必做）
```
- 存镜像：控制台 → 更多 → 保存镜像（**同区才能复用**）
- 关机：按量计费，不用就关

## 六、已知的坑

| 坑 | 现象 | 处理 |
|---|---|---|
| 带宽 100M | 16G 模型下 21 分钟 | 临时开大带宽 / 挂公共模型库 / aria2 多线程 |
| 镜像跨区 | 华北镜像华南用不了 | 用 `deploy_qwen21.py` 重建 |
| 磁盘 30G | 装完只剩 10G | 换 50G 盘；大模型放 `/root/sj-fs` 再软链 |
| 软链全断 | 模型下拉里一堆点不开 | `/root/sj-data` 没挂载，145 个坏链；挂公共模型库即可 |
| PE 节点标红 | 提示缺 `qwen3.5_9b_..._pe_t2i` | 右键 Bypass，不影响出图 |
| Qwen3.5 塞进 24G | 27B/35B 起不来 | 用 9B，或换 2×4090 / 80G 卡 |

---

## 七、一页总结

1. **文本用 Qwen3.5-9B，生图用 Qwen-Image 2.1，两条线分开**
2. **24G 卡只够 9B**，27B 以上要加卡，性价比不高
3. **镜像社区有现成 qwen3.5 镜像**，先试它；生图用 `deploy_qwen21.py`
4. **部署顺序**：选机器 → 选镜像 → 起服务 → 验证 → 批量 → 收尾
5. **三个必查**：显存够不够、磁盘够不够、带宽多少
