# AI 短剧全流程通用 Prompt 标准库 (100% 题材解耦版)

> **设计原则**：
> 1. **彻底解耦特定小说**：所有模板均采用 `{参数占位符}` 结构，适用于都市、古装、仙侠、末世、悬疑、科幻等任意小说改编。
> 2. **只留生产必需项**：剔除一切冗余理论，仅保留【剧作拆解】、【母版定妆】、【三分类分镜合成】、【多镜视频生成】四大生产环节直接调用的标准 Prompt。

---

## 一、 剧作与故事板拆解通用系统 Prompt (LLM 阶段)

用于将任意小说原文转化为符合 18 道代码校验门的标准 JSON 资产（`cast.json` / `art.json` / `script.json` / `storyboard.json`）：

```markdown
# Role
你是一位工业级 AI 短剧总导演与结构化分镜师。请将输入的【小说原文/章节】拆解为标准化的短剧生产 JSON 数据。

# 核心拆解铁律（通用任意题材）
1. **角色提取 (`cast.json`)**：
   - 为每位角色分配唯一编号（`C01`, `C02`...）；
   - `promptLocal` 必须提取角色不可变的视觉锚点：`{年龄段}中国{性别}，{脸型骨相与眼神气质}，{发型与发饰不变量}，{核心服装款式、材质与主色调}`，严禁写入单场临时动作。
2. **美术资产 (`art.json`)**：
   - 场景（`S01`, `S02`...）：描述空间几何结构、建筑年代/风格、主光源方向与色调，必须声明“无人空景”；
   - 道具（`P01`, `P02`...）：描述物理材质、表面磨损细节、尺寸参照，必须声明“纯白背景或微距特写，无手部无人物”。
3. **节拍剧本 (`script.json`)**：
   - 单集目标时长：`{单集目标秒数，默认 90}` 秒（允许误差 ±15%）；
   - 前 3 拍内必须完成具象视觉冲突（冷开场钩子 `hookBeat`），单句台词严格 ≤ 35 字。
4. **故事板分镜 (`storyboard.json`)**：
   - 结构：每集拆分为若干视频段（`segments`，每段 ≤ 15 秒），每段包含 2~4 个分镜切点（`cuts`，每切 2~5 秒）；
   - 台词装入校验：分镜认领的台词折算时长（按约 4.5 字/秒计）必须严格 ≤ 该分镜分配秒数；
   - 景别枚举（必填进画面描述）：`大远景` / `远景` / `全景` / `中全景` / `中景` / `中近景` / `近景` / `特写` / `大特写`；
   - 视频提示词禁真名：在生成下游视频提示词（`h3Prompt` / `seedance`）时，禁止出现角色姓名，统一使用通用身份代称（如 `a young man in black robe` / `黑衣青年`）。
```

## 二、 母版锚点定妆通用 Prompt (阶段 2：生成唯一基准图)

> **用途**：在生图初期，为每个角色生成唯一一张 `master_id/{角色ID}.png`，以及核心场景/道具基准图。

### 1. 角色唯一正脸母版 Prompt（文生图，`2:3` 竖屏 `1056×1584`）

#### 【预设 A：写实国剧风 (Realistic)】
```text
正面全身或标准半身定妆照，人物正对镜头自然站立，双肩、髋部与面部完全正对前方，鼻梁位于面部正中线，双耳对称可见。
人物设定：{年龄}中国{性别}，{骨相特征，如：剑眉星目/清冷鹅蛋脸/硬朗下颌线}，{眼神与常态微表情}，清爽哑光自然健康肤质，无油腻反光。
发型与配饰：{发型描述与标志性配饰}。
服装造型：{外穿衣物款式、材质纹理与主色调}，{内搭与领口细节}。
摄影与背景：纯白或浅灰无缝影棚背景，柔和有方向感的主光搭配自然补光，85mm人像定焦镜头，f/5.6光圈，真实光学摄影质感，无美颜磨皮，单人完整画面，无边框无文字。
```

#### 【预设 B：精品 2D 漫剧风 (Anime)】
```text
高品质2D动画官方角色设定单图，人物正对镜头自然站立，双肩与面部完全正对正前方，双耳对称可见。
人物设定：{年龄}{性别}动漫角色，{五官特征与瞳色眼神}，{发型发色与标志性发饰}。
服装造型：{服装款式、层次设计与色彩搭配}。
画风与背景：干净利落的等粗线稿，细腻赛璐璐分层上色，柔和阴影搭配清脆高光，纯白干净背景，单人单视图，无多视角拼图，无文字水印。
```

### 2. 纯场景空镜设定图 Prompt
```text

```

### 3. 纯道具特写设定图 Prompt
```text

```

## 三、 故事板分镜合成通用 Prompt (阶段 3：Qwen-Image-Edit 批量生产)

> **用途**：由 `03_universal_drama_engine.py` 自动组装并推流至 ComfyUI。严格按镜头类别三分类解耦，防止人像词污染道具与空镜。

### 1. 角色动作分镜模板（分类：`character` | 挂载 `master_id/{角色ID}.png` | `denoise = 1.0`）
```text
电影实拍级剧照，8K超高清画质，景别：{景别}，运镜视角：{运镜}，{焦段，默认50mm镜头}拍摄。
出镜人物角色：{角色ID对应的中文外貌与服装不变量描述}（严格保持参考图中的人物面部五官骨相、发型与服装完全一致）。
人物动作与剧情走位：{当前分镜具体肢体动作、视线方向、手部交互与表情变化}。
场景环境与光影：{当前分镜所在场景空间、道具交互与光影氛围}{通用正向画质后缀}
```

### 2. 纯道具特写分镜模板（分类：`prop` | 不挂任何参考图 | 纯文生图）
```text
微距电影摄影特写，100mm微距镜头，焦点极清晰对准物体本身，景深自然柔和，真实物理材质与细节纹理。
无人物面孔，无人物肢体，纯道具特写。
具体物体状态与细节：{当前分镜道具特写描述}。环境背景：{当前分镜背景环境与光影}{通用正向画质后缀}
```

### 3. 纯场景空镜分镜模板（分类：`scene` | 不挂任何参考图 | 纯文生图）
```text
电影宽画幅全景空镜，24mm变形广角镜头，宏大空间纵深与建筑透视，大气磅礴的自然光影与空间纵深感，空镜头，无人物肖像。
场景与氛围：{当前分镜环境动态描述}。环境参考：{当前分镜建筑、天气与光照特征}{通用正向画质后缀}
```

### 4. 通用正向画质后缀与通用负向词（Negative Prompt）

- **【写实风正向后缀 (`REALISTIC_SUFFIX`)】**：
  ```text
  ，院线电影胶片质感，35mm电影镜头，真实细腻皮肤质感，自然光影层次，清爽哑光肤质，无油腻反光，深邃光学景深，大片级构图调色，大师级实拍RAW质感，单帧满画幅无边框无字幕。
  ```
- **【漫剧风正向后缀 (`ANIME_SUFFIX`)】**：
  ```text
  ，剧场版高定2D动画电影质感，精湛作画线条，细腻赛璐璐光影层次，电影级大景深构图，色彩饱满通透，单帧满画幅无边框无字幕。
  ```

- **【通用负向提示词 (`NEGATIVE_PROMPT`)】**：
  ```text
  低画质，模糊，磨皮塑料脸，满脸油光，猪油反光，畸变，多手多脚，手指畸形，欧美混血面孔，分格边框，多视图拼图，字幕，水印，文字，签名
  ```

## 四、 多镜音画同出视频通用 Prompt (阶段 4：MiniMax H3 / Seedance)

> **用途**：一段视频（12~15 秒，含 2~4 个切点关键帧 `f1.png`, `f2.png`, `f3.png`）一次性生成多镜有声视频。

### 1. 多切点视频通用模板（英文官方标准口径，台词保留原中文）
```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 2) aligns with the {切点2秒数，如 3.00}-second mark of the target video; Picture 3 (from Shot 3) aligns with the {切点3秒数，如 7.00}-second mark of the target video.

integrated_multimodal_description:
[Shot 1] {运镜官方英文词，如: In a static medium shot / The camera slowly pushes in}, anchored by <Picture 1>, {角色通用身份代称，禁写姓名，如: a 25-year-old young man in dark attire (S1)} {当前镜头具体连续动作描述}. (S1) says in a {情绪与语速，如: calm, low voice}, <d>[Chinese] {逐字台词原文，标点完全一致}</d>.
[Shot 2] At 00:{切点2格式，如 03.000}, the camera cuts to <Picture 2>: {运镜官方英文词}, {Shot 2 角色动作与反应描述}. {若有台词: (S2, a middle-aged man in armor) replies angrily, <d>[Chinese] {逐字台词原文}</d>.}
[Shot 3] At 00:{切点3格式，如 07.000}, the camera cuts to <Picture 3>: {运镜官方英文词}, {Shot 3 动作收尾与悬念定格描述}.

overall_soundscape: {1~3句英文描述环境底噪与动作拟音，如: Crisp footsteps echoing in a stone hall, rustling fabric, and distant wind.}

non_diegetic_music: {1~2句英文描述背景配乐配器与节奏，无配乐则写 N/A，如: Tense, low-tempo orchestral strings building suspense.}
```

### 2. H3 强制合规运镜官方词表（必须在每个 `[Shot k]` 行内出现）
- **固定镜头**：`static shot`（中文模式：`固定`）
- **推镜头**：`push in`（中文模式：`推`）
- **拉镜头**：`pull out`（中文模式：`拉`）
- **摇镜头**：`pan left` / `pan right` / `tilt up` / `tilt down`（中文模式：`摇`）
- **跟拍/移镜头**：`tracking shot` / `truck left` / `truck right`（中文模式：`跟拍` / `移`）
- **升降镜头**：`pedestal up` / `pedestal down`（中文模式：`升` / `降`）
